How the agents work

One data layer, four agents, one model

{{DIAGRAM}}

gpt-6-luna via Yale’s Portkey key: cheapest capable model, tool calling. Code does the heavy lifting (281 profiles → 25-person shortlist); every agent has a non-AI fallback.

One real run, traced

“Who can I collaborate with on climate and health in Kenya?”

  1. Looks up valid places, topics and priority codes
  2. Tries 4 exact searches (Kenya + climate & health): 0 people
  3. Relaxes: Kenya → 7; Climate & Health → 22
  4. Reads 5 profiles in detail
  5. Answers honestly: nobody has both; here’s who fits each part, and why
  6. 5 model requests · 14 tool calls · 18.6 s · $0.0011

Cost to run (measured, 18 real runs)

About two cents per user per month

$0.0005per Nexi answer · 7.6k input (75% cached) / 0.6k output tokens
$0.0034per team analysis · 31.8k in / 3.1k out · cached and shared per call
$0.0008per one-pager · 1.9k in / 1.3k out
$0.02per active user per month (15 questions, 3 calls, 2 drafts)
~$2per month at 100 users
~$197per month at 10,000 users (upper bound)

Cuts: small model, shortlist in code, result caching, prompt caching (halves chat cost), no AI on list pages. Trade-off seen: a 16-tool cap cut off a real question (raised to 30); rules vs. AI agree on 60% of top-5 picks.

Safety

Attacks refused, facts never invented

Read-only tools · facts copied from funders only · “has agreed / is interested” claims stripped · scraped text cleaned of instructions · sign-in for drafting · per-run caps, rate limit, daily budget · 12 safety tests pass
